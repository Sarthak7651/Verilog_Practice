# Verilog Practice

A collection of Verilog HDL programs and digital design experiments created for learning and practicing hardware description and RTL design.

This repository contains simple implementations and experiments that help build an understanding of how digital circuits are described, simulated, and represented using Verilog.

## About

The purpose of this repository is to practice the fundamentals of **Verilog HDL** and gradually develop a stronger understanding of digital logic and hardware design.

It can be used as a reference for students, beginners, or anyone getting started with Verilog and RTL development.

## Topics Covered

* Verilog HDL fundamentals
* Combinational logic
* Sequential logic
* Registers and counters
* Digital circuit design
* Modular design
* Testbenches
* Simulation
* RTL concepts
* Basic arithmetic circuits
* Hardware schematics

## Repository Structure

The repository is organized into different folders, with each folder focusing on a particular Verilog concept or digital design problem.

```text
Verilog_Practice/
├── Practice Modules
├── Testbenches
├── Simulation Files
└── Schematics
```

The examples range from basic Verilog constructs to small digital circuits, making the repository suitable for hands-on practice.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Sarthak7651/Verilog_Practice.git
cd Verilog_Practice
```

Open the Verilog (`.v`) files using your preferred Verilog editor, simulator, or FPGA development environment.

## Tools

The Verilog programs can be simulated or synthesized using tools such as:

* Icarus Verilog
* Verilator
* ModelSim / Questa
* Xilinx Vivado
* Other Verilog-compatible tools

## Learning Objectives

This repository aims to help with:

* Understanding Verilog syntax and constructs
* Translating digital logic into HDL
* Writing and organizing RTL modules
* Creating basic testbenches
* Simulating digital designs
* Understanding hardware behavior from Verilog code
* Developing a foundation for more advanced FPGA and digital design projects
